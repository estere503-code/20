# Friends Included Ltd finance system

This repository contains the submission-ready Next.js finance application for the Friends Included Ltd Day 4 homework.

## Run locally

The real application lives in the work directory:

1. cd work
2. Copy work/.env.example to work/.env.local and fill in server-side secrets. Never commit .env.local.
3. Run the Supabase schema from work/schema.sql.
4. Run npm install and then npm run dev inside work.
5. Run npx vitest run inside work to verify the calculation tests.
